MagicBricks automatic browser capture

You complete any CAPTCHA yourself. RentIQ loads listings, enriches latitude/longitude, and imports the data automatically.

One-time browser extension setup

  1. Download the Chrome extension
  2. Extract the ZIP on your computer.
  3. Open chrome://extensions, enable Developer mode, then choose Load unpacked.
  4. Select the extracted browser_extension folder.
  5. After future code updates, click Reload on this extension in chrome://extensions.

Start automatic capture

The extension waits for manual CAPTCHA completion, auto-scrolls, extracts card coordinates, and opens only listings whose coordinates are missing.

Automatic workflow

  1. Enter the city and locality, then click the button above.
  2. Complete a CAPTCHA manually if MagicBricks shows one.
  3. RentIQ auto-scrolls until the current results page stops loading new cards.
  4. Latitude/longitude is first read from each card's embedded JSON-LD.
  5. For missing coordinates, one background detail tab is reused automatically and closed after enrichment.
  6. The listings, coordinates, and property links are saved to SQLite and CSV.

Important limitation

RentIQ does not solve, skip, bypass, or hide CAPTCHA challenges. It pauses and brings the affected MagicBricks tab forward only when manual verification is required. It processes the dynamically loaded listings on the current search-results page.
