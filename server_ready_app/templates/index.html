MagicBricks browser-assisted capture

You browse normally and complete any CAPTCHA yourself. The server only receives the listings you explicitly send.

One-time browser extension setup

  1. Download the Chrome extension
  2. Extract the ZIP on your computer.
  3. Open chrome://extensions, enable Developer mode, then choose Load unpacked.
  4. Select the extracted browser_extension folder.
  5. Pin RentIQ MagicBricks Capture to the Chrome toolbar.

Server URL for the extension: {{ server_url }}

Open the MagicBricks search

After the page opens, complete any CAPTCHA, scroll through the listings, then click the RentIQ extension.

Capture workflow

  1. Open MagicBricks using the button above.
  2. Complete any CAPTCHA manually.
  3. Wait for property cards to load and scroll to load more visible listings.
  4. Click the RentIQ extension icon.
  5. Confirm the server URL and click Capture visible listings.
  6. Return here; this page refreshes automatically.
